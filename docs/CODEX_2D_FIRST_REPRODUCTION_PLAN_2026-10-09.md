## 2026-10-10 사용자 변경: Fig.7 grounded body 제외

Fig.7의 grounded body case는 현재 재현 조건에서 제외한다. Fig.7(c)의 grounded 파형, Fig.7(d)의 grounded RH threshold(16.8k), Fig.7(e)의 grounded body rise(1.8 mV) 및 접지 억제 설명을 현재 재현율·RMS·통과/종료 조건에 넣지 않는다. 부유 몸체의 II OFF/ON, 방향별 RH 및 body 상승은 계속 검증한다.

기존 `legacy52`는 이력용이다. 그 목록에서 grounded 1개를 제외한 현재 지표는 `scope51`이며, 제외 항목은 실패·미실행으로 세지 않는다. 확장 목록의 grounded 관련 항목도 제외하고 포함 목록과 분모를 함께 공개한다. 이 변경은 논문 내용 변경이나 다른 Case의 허용오차 완화를 뜻하지 않는다.

## 1. 목표와 실행 순서

목표는 Cho의 공개된 구조·바이어스·현상·정량 결과를 일관된 TCAD 구성으로 재현하는 것이다. 원 저자의 덱과 미공개 계수가 없으므로, 수치가 맞는 것만으로 원래 덱과 완전히 동일하다고 주장하지 않는다. 미공개 가정은 끝까지 표시한다.

**우선순위: 기준·측정 정리 → 2D 수치 검증 → 자연 precharge → Id–Vg·쓰기 동시 재현 → 5개 Case의 FBE → 2D Y/Z 인접 셀 검증 → 3D 단일 셀·공간 결합 → 3D 미니어레이 최종 재현.**

- 이미 제작한 `ga_c2`·`gax_c2`는 보존한다. 구조·용량 참고 자료로 활용하며, 현재의 2D 쓰기 부족을 해결하지 않은 채 전체 배열 과도 해석으로 확대하지 않는다.
- 2D의 완성 대상은 단면 구조, 전류·용량 단위, 수치 수렴, 자연 충전, 단일 셀 특성 및 설명 가능한 FBE이다. X 방향 간섭은 2D 완성 기준에 넣지 않는다.
- 2D에서 모든 3D Row Hammer 수치를 맞출 때까지 무한 보정하지 않는다. 단일 셀을 검증한 뒤 Y/Z 검증에서 남는 차이를 정량화하고 3D로 넘긴다.
- 2D 단일 셀에서도 해결되지 않은 차이가 남으면 “2D 완성”으로 부르지 않는다. 아래 G2의 제한된 3D 진단 조건으로만 차원의 영향을 확인한다.

## 3. 현재 기준과 재현 판정 범위

### 3.1 현행 기준

- 현행 소자는 `fin7`이다. `codex_validation/CURRENT_BASELINE.json`의 fin3 표기는 10월 7일의 오래된 기록이므로 새 실험의 기준으로 사용하지 않는다.
- 저장 용량은 본문 기준: body 30/20/10 nm에 각각 5.1/4.2/3.6 fF. 자연 쓰기를 맞추기 위해 과거의 1.8 fF로 돌아가지 않는다.
- BL 접촉은 기둥 끝, 현재 2D 기준은 셀에서 Z 피치 두 개 이상 떨어진 배치이다. 접촉과 몸체 사이의 좌표·거리를 기록한다.
- BL 면의 급격한 접합과 BL 쪽 spacer 아래 body의 채널 도핑은 사용자 고정 사항이다.
- HfO2/Si3N4, 300 K, 수명, 터널링 계수 및 미공개 옵션은 현행 가정이다. Cho 명시값으로 승격하지 않는다.
- 기준의 충돌 이온화 OFF 계열과 Fig.7용 ON 계열을 각각 추적한다. 한 계열에서 쓰기 때만 ON, FBE 때만 OFF로 바꾸지 않는다. Fig.4/5/8의 ON/OFF는 원문에 명확히 제시되지 않았으므로 추정과 검증 결과를 구분한다.

**이미 끝난 결과:** CxS4/CxS8 네 실행은 10월 9일 16:45까지 정상 종료했다. 4배/8배의 순 SN 손실은 −0.022800/−0.022066 mV, 종료 body 순상승은 26.593/23.578 mV이다. Attack 전류 적분 잔차 절댓값은 7.87e−5→3.30e−5 fC로 감소했다. 이것은 안정된 큰 RH 붕괴를 확인한 결과가 아니다.

1. Codex가 1배/4배/8배의 덱·파라미터·메시·실제 시간 스텝·Newton 로그를 대조한다. `MaxStep`이 같다고 실제 적분 스텝도 같다고 가정하지 않는다. 출력 요청이 시간 스텝에 영향을 주는지는 설치된 U-2022.12 매뉴얼과 로그로 확인한다.
2. 저장 격자와 내부 시간 스텝을 구분한다. 저장 격자를 고정하고 기존 MaxStep h=9.4 ps의 h/2, h/4, 필요 시 h/8로 Z/II ON attack+idle을 비교한다. 우선 4건, 미수렴이면 추가 2건. 출력점이 solver 스텝을 강제한다면 실제 스텝 제어에 맞게 실행 설계를 먼저 수정한다.
3. 시간 수렴 뒤 접합·body·고전계 영역을 단계적으로 세분한 메시 2종에서 같은 쌍을 비교한다(추가 최대 4건). 물리 모델·초기화·도핑은 고정한다.
4. 수치 검증용으로 기존 SN reset을 유지해 변화 원인을 한정한다. 그 다음 P2에서 자연 초기화로 전환한다. 기존 작은 음의 순손실을 물리적 이득으로 해석하지 않는다.

**Claude 역할:** mesh refinement 지원, 경계·접촉이 바뀌지 않았는지 확인, 통과한 시간·메시·저장 설정을 공식 생성기에 반영한다. 같은 수치 검증 배치를 별도로 반복하지 않는다.

**수치 목표 제안:** 판독 허용오차의 20% 이내를 수치오차 예산으로 삼는다. 예를 들어 IV 전압 4 mV, 쓰기 6 mV, body 6 mV, C5 손실 0.1 mV 이하. RH 최소 기울기 0.006 mV/cycle 판정에는 수치 차이 ≤0.0012 mV/cycle를 목표로 한다. 이들은 계획 기준이며 논문 오차가 아니다. 거의 0인 순효과의 부호를 주장하려면 그 순효과보다 작은 오차가 추가로 필요하다.

**G1 종료 조건:** 연속 두 refinement에서 주요 값과 합격/불합격 결론이 안정적이고, CsΔV+∫I 단자 전하 잔차가 목표 손실의 판정을 뒤집지 않는다. KCL 평가 구간은 SN이 외부 전압원에서 해제된 구간이며, 전체 단자 전류의 변위전류를 포함한다. 수치 실패와 물리 미재현을 분리한다.

### P2. 자연 precharge 원인 분리 — Claude 실행 주관

**첫 최소 배치: 2건.** 기존 Z pair의 floating/OFF, floating/기본 ON을 동일한 각 원본 덱에서 복사해 SN 강제 설정만 제거하고 write→WL off→hold까지만 실행한다. 공격 전까지의 이력을 기록한다. 현재 raw에서 강제 보정 직전 SN은 각각 약 1.021/1.031 V이다. 기존 reset 실행을 대조군으로 재사용한다. Grounded 덱과 raw는 이력 자료로 보존하며 현재 배치에서 제외한다.

- 전압·펄스·용량·구조·모델은 해당 원본과 일치시킨다. underlap 도핑, 접합 위치, Cs를 함께 바꾸지 않는다.
- 초기 평형, write peak, WL-off 직전/직후, BL 전환, 해머 직전의 SN, body 평균/중심 전위, 정공 수, 단자 e/h/변위전류를 저장한다.
- SN과 BL 사이 전압·준페르미 전위 분포를 읽어 채널/BL 쪽 underlap/접촉의 전압 분배를 산출한다. 기존 “54–80% underlap” 결과를 새 자연 초기화에서도 확인한다.
- `Cs·dV/dt`와 SN 단자 total current의 전하 수지를 비교한다. 보이는 충전 곡선의 기울기를 채널 전류와 자동으로 동일시하지 않는다.
- 두 floating 구성의 충전 부족 구간과 II 영향, 자연 body 이력을 비교한다. Grounded 충전 부족은 현재 P2 종료 조건에 넣지 않는다.

**Codex:** 강제 설정 제거 diff, 소자 입력 해시, 중복 시각 처리, 전하 수지, 각 상태의 비교 가능성을 독립 검사한다. 사용한 시각이 같아도 reset 전후 해가 다르면 별개로 취급한다.

**P2 종료 조건:** 충전 부족이 발생하는 구간·전류·body 상태를 원시 자료로 특정한다. 부족을 설명했다고 쓰기 재현 성공으로 선언하지 않는다. 쓰기가 부족한 구성은 P3 개선 대상으로 넘어간다.

### P3. 2D Id–Vg와 쓰기의 동시 개선 — Claude 실행·모델 개선, Codex 교차검증

**먼저 비교할 소수 구성:** 아래 계열을 사용하되 각각의 전 구간에서 모델을 일관되게 유지한다.

| 구성 | 용도 | 변경 축 |
|---|---|---|
| M0 | fin7 OFF 기준 | 기준 유지 |
| M1 | fin7 기본 avalanche ON 기준 | II on/off만 |
| M2 | 기존 vanOverstraeten의 ElectricField 후보 | M1에서 구동력만 변경 |
| M3, 조건부 | 기존 round38의 UniBo+ElectricField 후보 | M2에서 avalanche 종류만 변경 |

각 구성은 C2의 Id–Vg, load-line, 자연 write+hold 3종으로 먼저 판단한다. M0/M1의 기존 결과 중 입력·수치 기준이 일치하는 것은 재사용한다. 실패 후보를 5개 Case 또는 3D로 확대하지 않는다. M3는 M2의 비교로 모델 종류를 가를 필요가 생겼을 때만 수행한다. 동시에 모델 종류와 spacer를 바꾸지 않는다.

**Id–Vg가 DC로 존재하지 않거나 경로 의존이면:** 수치 스윕 속도를 바꾸어 맞는 곡선을 고르지 않는다. 평형/준정적/과도 스윕의 정의와 방향·속도·body 이력을 분리한다. 저자 측정 정의가 미공개면 그 구성을 ‘측정 정의 미확정’으로 남긴다. 단순 정상 종료를 DC 재현으로 처리하지 않는다.

**후속 보정 순서:** 총전류·바이어스·전극과 폭 확인 → on-current·load-line·write → subthreshold/문턱 → 누설·GIDL → 자연 body history. 이미 허용된 문헌과 기존 실험이 뒷받침하는 변경만 한 번에 하나 적용한다. 이동도·접촉·터널링 계수 등의 신규 값이 필요하면 출처와 후보 범위를 먼저 제시한다. 정규화가 불명확하다는 이유로 전류를 2배 만드는 보정은 하지 않는다.

터널링 기작을 해석할 때 Lee 외 TED 2026 survey Fig.3, Sec.II-B의 GIDL 정공 축적→기생 n-p-n BJT 바이어스→BL 변화 시 전류 스파이크 설명을 참고한다. 이 설명은 특정 Sentaurus 계수·옵션을 확정하지 않는다.

**후보 확대:** C2가 통과하면 C1–C5의 Id–Vg+자연 write/hold를 평가한다. 기준 곡선이 C2뿐인 쓰기는 나머지 Case에서 내부 일관성·자연 충전 확인으로 표시한다. 계열마다 구조·물성은 공통이고 Case의 명시 설계 변수만 바뀐다.

**G2-A, 2D 단일 셀 통과:** C2의 네 쓰기 점과 자연 초기 상태, Case별 IV, 관련 수치 검증을 동시에 충족한다. 다섯 Case의 최악 항목을 공개하고 초기 상태의 강제 보충이 없어야 한다.

**G2-B, 2D 한계 확인:** 제한된 근거 있는 후보를 검증해도 위 항목이 양립하지 않으면 불일치 표를 확정한다. 이때 전체 mini-array 대신 **동일 단면·동일 lumped Cs의 3D 단일 셀 대조**만 계획한다. 목표는 유한 폭/끝면 전계 때문에 write가 달라지는지 한 가지를 가르는 것이다. 2D 미완료 상태를 명시하고, 새로운 소자 물성을 동시에 바꾸지 않는다.

### P4. 자연 이력의 FBE — Claude 실행·개선 주관

검증된 계열에서 C1–C5마다 동일한 자연 write→WL off→hold 상태를 만든다. 각 상태에서 BL pulse와 BL hold 대조를 분기한다. **한 계열당 5개 pulse+5개 hold, 최대 10건**이며 입력이 같은 기존 raw는 재사용한다. 필요 모델 계열이 둘이면 결과를 섞지 않고 각각 보고한다.

- 200 ns 전체 파형과 9개 BL 저전위 구간을 평가한다. 첫 구간만 맞추고 끝내지 않는다.
- 논문 비교는 원래의 총 SN 손실로 수행한다. pulse−hold는 원인 분리를 위한 보조 지표다.
- body 중심·게이트 아래 평균·프로파일을 함께 저장하되 채점할 정의·시각은 실행 전에 고정한다. 잘 맞는 위치를 사후 선택하지 않는다.
- 정공 생성 위치와 body의 유입/유출·재결합을 조사한다. SN의 e/h/변위전류와 누설을 연결한다.
- C5의 ≤0.5 mV는 이 단계의 필수 항목이다. mesh/time, hold 누설, 소스·SN 접합 BTBT, 자연 body 이력 순으로 원인을 가른다.
- 인위적 pair generation·장시간 SN clamp·추가 reset으로 막대를 맞춘 실행은 기존 진단으로 보존한다. 자연 상태 재현 점수에 합치지 않는다. 과거 720조건 탐색을 반복하지 않는다.

**Codex:** 각 Case의 추출값·최악 오차·전하 수지를 독립 산출하고, 막대가 ‘입력 조건’에서 ‘예측 결과’로 전환되었는지 점검한다. 차이를 설명할 수 있는 다음 한 가지 대조를 제안한다.

**G3 종료 조건:** body rise와 첫/후기 손실을 같은 자연 이력에서 동시 평가하고 전체 Case 추세 및 문장 판정을 제시한다. 불일치가 남으면 원인과 차원 의존 가능성을 명시한다. 미공개 이력 없이는 맞지 않으면 그 한계를 결과로 남긴다.

### P5. 2D 인접 셀과 RH 기작 분리 — Claude 실행, Codex 인과 검증

소자 설계 C2, 자연 precharge, 피해 WL=0 V, BL=0.55 V를 사용한다. 다음 4개 floating 조건의 attack/idle 쌍, **한 비교 세트 8건**이다.

| 조건 | 가르는 것 |
|---|---|
| Y, floating, II OFF | 수평 인접·기본 누설/결합 |
| Z, floating, II OFF | 수직 인접·기본 누설/결합 |
| Y, floating, II ON | II 영향이 Z에만 특이적인지 |
| Z, floating, II ON | 큰 body 상승과 SN 손실의 연결 |

각 attack/idle은 동일 restart 파일에서 분기하며 해머 직전 SN/body/정공과 해시를 확인한다. 구성 간에는 자연 충전 결과가 다를 수 있으므로 이를 보고한다. 같은 SN을 강제한 보조 진단을 추가하더라도 자연 재현과 다른 표로 둔다.

기록: 방향별 시간 파형, 가역 SN 스윙, 10주기 및 마지막 5주기의 같은 위상 손실, idle 및 순손실, body 전위·정공, 공격/피해 영역별 II/BTBT/SRH와 경계 정공 flux, SN 전류와 채널 장벽. 연속방정식 수지를 검사해 ‘발생→이동/축적→장벽 변화→SN 전하 유출’의 연결을 확인한다.

**G4 종료 조건:** 큰 Z floating 손실/II OFF 억제/Y와의 방향 차이를 각각 판정한다. Grounded 억제는 현재 G4 조건에서 제외한다. 2D에서 RH 수치가 맞지 않는다는 이유만으로 기본 소자 물성을 다시 임의 보정하지 않는다. 특히 전체 II 생성량만으로 피해 body 생성 위치를 단정하지 않는다. X는 3D 단계에 남긴다.

### P6. 3D로 이전: 단일 셀 → 결합 AC → 필요한 pair → 미니어레이

**Claude 실행 주관**, **Codex 입력 대응·결과 검증**. P0–P5의 결과와 G2-A/G2-B 중 어떤 경로인지 확인한 뒤 착수한다.

1. **좌표표와 용량 대응.** Lg/spacer/BL/Cap/WL pitch의 기준점을 정의한다. BL 50/100 nm, capacitor pillar 반지름의 유전막 포함 여부, 길이 100 nm의 실제 facing area를 해결하거나 가정별로 구분한다. 사진 비례를 명시 치수처럼 취급하지 않는다.
2. **최소 3D 단일 셀 대조.** 2D와 같은 단면·물성·접촉·Cs로 IV/write를 먼저 비교한다. 이후 기하 커패시터를 붙인다. 기하 Cs≈3.0 fF와 lumped 4.2 fF의 영향을 한 번에 섞지 않는다. 총 용량·단자별 결합을 측정하고 double counting을 검사한다. 목표 Cs를 위한 임의 덧셈이나 새 유전율 보정은 복제 근거로 사용하지 않는다.
3. **기존 gax_c2 AC.** 접촉 이름 처리와 Fig.2 대조·메시 점검 후 DgxC_c2를 1건 수행한다. X/Y/Z 및 자체 WL/BL/판 전극의 전체 행렬, 대칭성·전하 보존·경계조건을 검토한다. 필요하면 2D 통과 후 실제 OFF 바이어스에서 추가 소신호를 계산한다.
4. **직접 소신호 비교.** ΔV≈Ccouple/Ctotal·ΔVWL은 1차 추정이다. 0.70 mV에 맞는 1.17 또는 1.6 aF를 목표값으로 보정하지 않는다. full matrix와 SN 경계조건으로 비교하고 작은 항의 메시 민감도를 확인한다.
5. **3D pair/국소 배열 과도 해석.** 활성 셀·접합·고전계 영역을 세분하고 필요한 인접 경계를 보존한다. OFF X/Y/Z×attack/idle 6건; ON Y/Z floating×attack/idle 4건을 우선한다. Grounded 쌍은 현재 재현 실행에서 제외한다. 최종 Fig.7(d)의 X ON 86.4k 항목 검증에는 X ON 쌍 2건도 포함한다. pair에서 외부 배열 경계 영향이 작다는 증거 없이 이를 전체 배열 결과로 대체하지 않는다.
6. **3×2×5 최종 검증.** 검증된 설정을 mini-array로 이전해 Fig.6/7의 최종 파형·표를 만든다. 현재 coarse 메시의 AC 정상 종료를 transistor transient 정확도의 증거로 사용하지 않는다.

3D 과도 해석은 cell 단위·pair 단위 실제 wall time, RAM, 저장량을 측정한 뒤 배치 크기를 정한다. 과거 AC는 291초였지만 peak RAM 20.3 GB였으며, 이를 모든 3D 실행의 비용으로 일반화하지 않는다. 서버 quota는 시작 직전에 갱신 확인한다.

## 5. 역할 분담과 소유권

| 업무 | Claude의 책임 | Codex의 책임 |
|---|---|---|
| 물리·기하 기준 | 공식 소자 정의·생성기·메시 유지 | 원문·치수·가정·단위 독립 검토 |
| 수치 검증 | 필요한 mesh 생성 지원, 통과 설정 반영 | P1 배치 실행 및 시간/메시/전하 수지 검증 |

양쪽 모두 분석한다. **Claude는 소자와 주요 물리 실험을 만들고 개선하며, Codex는 수치 검증을 직접 실행하고 재현 주장과 원인 해석을 독립적으로 검사한다.** 같은 조건을 두 큐에서 중복 실행하지 않는다.

Claude 관리 최상위 `params.py/make_runs.py/tools/runs/NOTES.md`는 Claude가 수정한다. Codex 구현·진단은 `vblhwl_3d_dram/codex_validation`과 Codex 결과 폴더에 둔다. 상대 파일은 읽고 패치 제안으로 전달한다. 공유 Git은 기존 소유권을 지키고, baseline 시각과 commit이 오래된 main/snapshot 기록을 덮어쓰는 최신 근거인지 명시한다. 병합 자체는 물리 재현의 선행 조건이 아니다.

실험 등록 필수 필드: 소유자, 실험 ID, 질문/가설, 바뀌는 변수, 고정 변수, source figure/paragraph, device Case/topology, 모델 계열, 초기 이력, mesh·deck·parameter 해시, 수치 설정, 예상 작업 수·메모리·저장량, 성공/중단 기준, 재사용 raw, 시작/종료 시각, 결론.

각 round는 `가설 → 최소 대조 → raw 공개 → 양쪽 판정 → 채택/기각 → 다음 가설` 순서로 끝낸다. 결과가 수치 오차보다 작거나 조건이 다른 경우 대량 탐색으로 넘어가지 않는다.

## 7. 최종 완료 판정과 인수 자료

‘Cho 소자 재현 완료’는 전체 퍼센트 하나가 아니라 다음 자료로 판단한다.

1. **구조:** 원문 치수·재료 가정·접촉·도핑·2D/3D 대응표, 실제 mesh 검증 및 좌표 그림.
2. **단일 셀:** Fig.5(c), Fig.4(a), 자연 precharge 종료·hold 상태, 전류/전하 수지와 수치 수렴.
3. **FBE:** C1–C5의 같은 자연 이력에서 body rise와 전체 손실 파형, C5 상한, 문장별 추세.
4. **RH:** OFF/ON, X/Y/Z, floating, attack/idle의 가역/잔류/누적 효과와 원인; Fig.7의 큰 Z 손실·body 상승·방향 선택성.
5. **용량·sense margin:** 본문 Cs와 기하 Cs 구분, [9]의 CBL, 층수와 sense margin 계산 재검토. 64 ms 식 계산과 실제 64 ms transient 검증은 구분한다.
6. **재현 패키지:** 실행 가능한 생성기·의존 버전·덱·파라미터·메시 해시·raw·추출기·목표표·최악 오차·미해결 항목. 라이선스 논문 PDF와 그림 crop은 Git에 넣지 않는다.

논문의 6F² DRAM 비교 소자 신규 복제와 64 ms 장시간 transient는 현재 Cho 3D 소자 복제 범위 밖의 후속 과제로 둔다. 일부 figure만 일치하거나 인위적 초기 상태가 필요한 경우 그 범위를 적어 **부분/조건부 재현**으로 인수한다.
