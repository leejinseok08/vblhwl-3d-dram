## 1. 완료된 분석: 출력 간격이 실제 계산 스텝도 바꿨다

기존 1배·4배·8배의 원본 덱과 solver 로그를 읽고 대조했다. 기존 배치는 CurrentPlot의 지정 출력점 수만 바꿨지만, **실제 solver가 그 시각들을 계산하도록 시간 스텝도 달라졌다.**

| Attack 실행 | 실제 첫 계산 스텝 [ps] | 해머 구간 최대 스텝 [ps] | accepted 해머 스텝 수 |
|---|---:|---:|---:|
| DptRzbi_zz | 0.50000 | 9.4000 | 651 |
| CxS4Atk | 0.31250 | 2.4722 | 1293 |
| CxS8Atk | 0.15625 | 1.2361 | 2376 |

따라서 앞선 ‘출력 해상도만 변경’은 **덱에서 바꾼 항목의 설명**이며, 실제 해석 시간 격자까지 고정됐다는 뜻이 아니다. 26.593→23.578 mV의 body 순상승 변화에는 실제 시간 이산화의 영향이 섞였다. 저장점 적분 오차만으로 설명하거나 물리 변화로 단정하지 않는다.

설치된 Sentaurus Device U-2022.12 User Guide pp.171–173을 확인했다. 지정 CurrentPlot은 저장 시점을 제한하고 중간 계산점을 생략할 수 있다. bare CurrentPlot은 내부 시점 전체를 기록한다. 후속 배치는 bare CurrentPlot을 공통으로 적용하고 MaxStep만 단계적으로 바꾼다.

기존 CxS4/CxS8 네 실행의 SN 손실과 body 상승을 독립 추출기로 다시 계산하여 이전 추출 결과와 1e-9 mV 이내 일치했다. 강제 초기화 시각에 여러 해가 저장되는 경우 마지막 해를 선택하는 처리도 점검했다. 배치의 전하 수지 비교 구간은 reset이 끝난 245–2125 ps이다.

## 3. 실행한 배치

| 실행 | MaxStep 배율 | 해머 plateau 최대 [ps] | 착수 상태 |
|---|---:|---:|---|
| CxN1Atk / CxN1Idle | 1 | 9.4 | 실행 중, PID40531/40532 |
| CxN2Atk / CxN2Idle | 1/2 | 4.7 | 대기 |
| CxN4Atk / CxN4Idle | 1/4 | 2.35 | 대기 |

각 단계 두 건 병렬, 실행당4 threads. 모든 transient 구간의 MaxStep을 같은 비율로 줄이며 InitialStep·MinStep·Newton 허용오차는 유지한다. 단계 실패 또는 불완전 출력이면 다음 단계는 시작하지 않는다.

Cs4.2 fF, AreaFactor0.1, 온도300 K, Hurkx+vanOverstraeten, BL/WL 펄스, 메시·접합·도핑·접촉은 고정이다. 현재의 강제 SN 초기화도 수치 진단을 위해 유지한다. 자연 충전과 물성 보정은 이 배치의 목적이 아니다.

현재 실행의 초기 구간에서 PLT와 solver 로그를 비교한 결과, CxN1Atk의 accepted endpoint41개, CxN1Idle40개가 모두 저장돼 있었다(로그 시간의 출력 자릿수 오차를 허용하여 대조). 이 확인은 초기 구간 확인이며, 최종 전체 구간도 다시 검사해야 한다.
