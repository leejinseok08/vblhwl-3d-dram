# 공유 패키지 검증

첫 공유 커밋 전에 다음을 통과했다.

- 공유 파일별SHA256 및 원래실행manifest의CMD/메쉬/파라미터/profile/대조군해시 일치.
- 각배치의메쉬PASS와승인manifest해시 일치. 이점검은실행당시기록이며새실행전원문검토를대신하지않는다.
- 저장된원시PLT로A1/A3/A2/기존조건판별/10개Dh1·Dfin감사분석을오프라인재생성. timestamp를제외하고구조/판정값일치. 수치값은플랫폼별부동소수점차이를허용해relative/absolute1e-10범위에서일치확인.
- A3와A2각대표덱의재실행준비를검증:Grid/Parameter/OpticalGenerationInput의경로만교체하고원래입력바이트를보존. 시뮬레이션은시작하지않았다.
- 공유text파일에서개인키/일반적인GitHub토큰패턴이없는지확인. 저장소는사용자요청에따라비공개다.

`python scripts/verify_package.py`로다시검증할수있다. 검증중재생성하는JSON/CSV는원래바이트로복원하므로검증자체가스냅샷을수정하지않는다. 원문논문PDF,설치매뉴얼전문및인증정보는패키지에포함하지않았다.
