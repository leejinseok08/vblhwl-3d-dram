# 완료된 진단 계산 스냅샷

이 폴더는 720개 조건 중 최초 완료8개(Case1/2)의 입력과 원시 출력이에요. 논문 원문이나 figure는 포함하지 않아요. `snapshot_inventory.json`의 시간과 SHA256이 보존 시점을 정의해요.

- `inputs/`: 실제 사용한 mesh와 기존 보정 Hurkx 파라미터 파일이에요.
- `runs/<run>/`: 변경하지 않은 원본 deck, run.json, 압축 PLT/TDR/log, 종료 코드예요.
- `results/`: 정공·전위·SN·전류 적분·생성/재결합 분리 분석이에요. `success`는 파일과 출력 검증 통과이며 논문 재현 성공이 아니에요.

재실행에는 라이선스가 있는 Sentaurus 환경이 필요해요. 원본 deck에는 실행 서버의 절대 경로가 남아 있어요. 별도 재실행 디렉터리에서 deck 사본의 Grid·Parameter·OpticalGenerationInput 경로를 `inputs/`의 해당 파일로 바꾸고 실제 구조와 논문 조건을 다시 점검해야 해요. 보존된 원본을 수정하거나 현재 서버 큐에 중복 투입하지 않아요.

현재 모델 계수와 재료는 이전 프로젝트의 보정값/가정이에요. 15.2µs 유지와 SN clamp/reset도 논문 명시 이력이 아니에요. 첫 BL-low 10.5ns 화면 선별 결과이며 200ns 전체 곡선의 재현 완료를 의미하지 않아요.

순위의 전위 기준은 중앙 electrostatic potential의 평형 대비 상승으로 고정했어요. 저자의 전위 위치·기준은 미확인이므로 다른 probe와 초기 SN 설정 후 기준도 원자료에서 함께 기록해요. Set을 통한 순간 reset 전하는 단자 전류 적분만으로 전부 측정했다고 가정하지 않아요.
