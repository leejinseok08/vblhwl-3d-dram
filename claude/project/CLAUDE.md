## 2D completion process (user, 2026-10-06: finish the device at the 2D level first; 3D is paused)
Every round, in this order. No step is skipped.
1. **Structure match against the paper, before any simulation** (user, said again on 2026-10-06): `bash tools/gt_start.sh
   <batch>.sh <jobs> <struct>:<tbody>[:<layers>[:yy]] ...`. It builds missing meshes without a device run and holds every
   structure of the batch against the paper: the dimensions of Fig.5(a)/(b) written into the structure file (Lg 100, Tox 5,
   Tg 20, dVOX 30, body thickness of the case, S/D 1e20, channel 1e18 / 1e16, both spacers 25 nm as drawn in Fig.2) and the
   junction positions and doping levels read back from the mesh. The batch starts only on ALL PASS; the check is kept in
   `runs/<batch>.check`. A structure the batch needs but the check does not name stops the start.
2. Run the configurations of the round (`make_runs.py`, `cfg2d(tag, what, change)`: one change per configuration against the
   baseline; runs `D<tag>I_c<n>` Id-Vg, `D<tag>W_c2` write, `D<tag>F_c<n>` FBE, `D<tag>R*` row hammer).
3. Score: `python3 tools/score2d.py [-v] <tags>` against `tools/paper_targets.py` (rms of deviation / tolerance per figure
   group: IV Fig.5(c), W Fig.4(a), BR Fig.8(a), L1 / L2 Fig.8(b),(c), RH Fig.6(e), RI Fig.7).
4. Adopt a change only if it lowers the score of the group it is meant for and leaves Fig.5(c) inside its tolerance; write
   the decision and its evidence into NOTES.md and the parameter table of the report.
5. New baseline, next round. Stop when no open parameter moves any score; what is left is listed as not reproducible.

Fig.7 on); initial state and body potential as the paper gives them (pre-charge of Fig.4(a); t = 0 = storage node at 1.1 V,

ideal case; candidates for anything the paper leaves open are picked by Claude and listed with their reason.
