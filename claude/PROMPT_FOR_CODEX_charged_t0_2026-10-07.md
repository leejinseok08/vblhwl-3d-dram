## 4. 실행마다 읽을 값

1. t_A(첫 하강 시작 직전): SN 전압, 몸체 정공 수, 몸체 전위 상승. 위치는 위의 9곳 전부, 기준은 과도 해석 시작(평형)과 초기 reset 종료 두 가지.
2. 유지의 마지막 21 ns 동안 몸체 중심 전위가 변한 양 (t_A − 21 ns → t_A).
3. SN 손실(t_A 기준): t_f + 3.25 ns, t_f + 5.25 ns, BL-low 1~9 각각의 끝(상승 시작 0.05 ns 전), t_f + 179.25 ns(논문 축 200 ns).
   Claude 표가 이 시각에서 읽은 값이라 같은 시각으로 맞춰요 (t_A = t_f − 0.05 ns).
4. BL-low 구간마다 줄어든 몸체 정공 수, BL 단자의 전자·정공 전류 적분, ∫I_SN dt와 Cs·ΔV.
