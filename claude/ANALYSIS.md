## 1. Fig. 4(a) 쓰기 곡선과 저장 노드 용량

- 논문 곡선: 저장 노드가 WL 상승 뒤 12 / 24 / 39 / 60 ps에 0.72 / 0.92 / 1.06 / 1.13 V.
- 전하 수지(모델 없이): 본문의 4.2 fF를 12 ps에 0.72 V 올리려면 평균 전류 I = C·ΔV/Δt = 252 µA가 필요해요. Fig. 5(c)에서 Case 2의 최대 전류는 229 µA예요.
  이 전류를 12 ps 내내 유지해도 0.66 V이고, 저장 노드가 소스라서 충전될수록 Vgs와 Vds가 함께 줄어 유지되지도 않아요.
- 모델(`Db0W_c2`, `DcsW_c2`): 4.2 fF에서 0.51 / 0.72 / 0.86 / 0.97 V, 1.8 fF에서 0.74 / 0.92 / 1.02 / 1.09 V. 충전 시간은 용량에 비례해요.
- 결론: Fig. 4(a)가 정해 주는 것은 "소자 폭당 저장 노드 용량" 18~20 fF/µm이고, 폭 0.1 µm(BL 피치 200 − 격리벽 100 nm)에서 1.8~2.0 fF예요.
  본문의 3.6 / 4.2 / 5.1 fF는 감지 여유 계산용 값으로 남겨 두었어요.
- **고친 판단.** 보고서 3.1절에서 "WL이 꺼질 때 노드가 1.168 → 1.10 V로 내려앉는 것"을 1.8 fF의 두 번째 근거로 적었는데, 독립된 근거가 아니에요.
  결합만으로 내려앉는다면 1.8 fF에서 67~76 mV가 맞지만, WL 꺼짐에서 정공–전자 쌍이 생긴다면(4절) 4.2 fF에서도 같은 값이 나와요
  (결합 30 mV + 1050개 × q ÷ 4.2 fF = 40 mV). 1.8 fF의 근거는 쓰기 곡선의 전하 수지 하나예요.
- 남는 차이: 1.8 fF에서도 곡선의 끝이 느려요 (39 / 60 ps에 1.02 / 1.09 V, 논문 1.06 / 1.13 V).
- 민감도(Case 2): 스페이서를 SiO2로 바꾸면 0.72 / 0.90 / 1.01 / 1.08 V, HfO2로 바꾸면 0.79 / 0.96 / 1.05 / 1.11 V (`DsxW_c2`, `DshW_c2`).
  HfO2는 끝이 논문에 가까워지지만 시작이 너무 빨라져서 점수는 나빠져요 (0.93 → 1.35). BL 기둥 폭 50 nm는 영향이 없어요 (`DbwW_c2`).

  (노드 단자 전하 0.068 fC, 몸체에 남는 정공 전하 0.17 fC의 약 40 %).

- Codex A1: BL 에지 뒤의 시간 간격을 5 ps / 50 ps로 줄여도 첫 손실이 0.059 mV 이내로 같아요. 첫 손실이 작은 것은 수치 설정 탓이 아니에요.
- 평균 점수가 Case별 불일치를 가려요 (Codex 지적). `fin`의 첫 손실 점수 0.84 안에서 Case 1은 18.9 대 55 mV로 2.9배 작아요.

## 4. 몸체 정공은 어디서 오는가

저자들의 설명: Lee 외, "Monolithically Stackable 1T1C 3-D DRAM: A Technical Survey", IEEE TED 73(3), 2026, Fig. 3과 II-B절 —
"holes generated by GIDL during BL precharge accumulate in the isolated body and can bias a parasitic n-p-n BJT". 이 설명은 Sentaurus 옵션이나 계수를
정해 주지 않아요. IRPS 논문은 충돌 이온화를 켰을 때 몸체가 뜬다고 해요 (Fig. 7(e): 끔 2.4 mV, 켬 665 mV).

### 4.2 충돌 이온화 계수를 키웠을 때 (진단. 배수는 어떤 문헌에서도 온 값이 아님)

van Overstraeten–de Man 계수 a(low), a(high)에 배수 k를 곱했어요. 쓰기 → WL 꺼짐 → 21 ns 유지, 대리 생성 없음 (`Dj<k>F_c<n>`, `Di1F_c<n>`).

| k | WL 꺼진 뒤 남는 정공, Case 1 / 2 / 3 / 4 / 5 | WL 하강 중 생긴 쌍 (Case 2 / 3) | WL 꺼짐에서 노드 변화 [mV] (Case 2) | t_A의 몸체 상승 [mV] |
|---|---|---|---|---|
| 1 | 103 / 35 / 9 / 2 / 1 | 4 / 8 | −71 | (대리 생성 전) |
| 2 | 140 / 56 / 21 / 4 / 1 | 9 / 20 | −71 | 207 / 69 / 14 / 3 / 1 |
| 3 | 165 / 75 / 36 / 10 / 2 | 18 / 34 | −72 | 225 / 86 / 23 / 7 / 2 |
| 4 | 185 / 91 / 50 / 8 / 4 | 26 / 47 | −73 | 239 / 98 / 31 / 6 / 3 |
| 5 | 207 / 119 / 114 / 14 / 7 | 46 / 105 | −74 | 253 / 117 / 63 / 9 / 5 |
| **7** | **1462 / 1334 / 1302 / 1320 / 1969** | 1596 / 1338 | −177 | 651 / 516 / 416 / 409 / 566 |
| 10 | — / 2349 / 2199 / 2185 / — | 2938 / 2364 | −262 | — / 750 / 623 / 608 / — |
| 논문 막대에 해당하는 값 | 1084 / 1056 / 1099 / 962 / 1138 | | | 555 / 445 / 365 / 320 / 368 |

읽은 것:

- k = 5와 7 사이에 문턱이 있어요. 문턱을 넘으면 WL이 꺼지는 순간(게이트가 1.8 → 0 V로 내려가며 부유 몸체를 끌어내릴 때) 저장 노드 쪽 게이트 끝에서
  이온화 적분이 1을 넘고, 몸체가 충전돼 전계가 사라질 때까지 쌍이 생겨요. 그래서 남는 정공 수가 **두께와 도핑이 달라도 거의 같아요**
  (k = 7에서 Case 2 / 3 / 4가 1334 / 1302 / 1320개, 편차 1.3 %). Fig. 8(a)가 "모든 Case에 같은 정공 전하"로 읽히는 것(2절)과 같은 성질이에요.
- k = 7에서 남는 양(약 1300개)은 손실 곡선에 맞는 전하(1.25배, `fin`의 1291 / 1295 / 1358 / 1193개)와 같아요. 막대(1050개)보다는 25 % 많아요.
- 유지 구간에 노드가 처지지 않아요 (−0.10 ~ −0.18 mV / 21 ns). 논문 곡선과 같은 점이에요. 대신 WL이 꺼지는 순간에 노드가 151~207 mV 내려가요
  (결합만일 때 64~76 mV). 덱은 그 뒤에 노드를 1.1 V로 다시 놓아요.
- Case 5(WF 5.0)는 다르게 움직여요: 1969개, 상승 566 mV(논문 368). WL 하강 중에 쌍 1556개가 생기는데 노드는 결합분(−60 mV)만 내려가요.
  전자가 저장 노드가 아닌 쪽으로 빠진다는 뜻인데, 어느 접합에서 생기는지는 아직 확인하지 않았어요.
- k = 10의 Case 1, 5와 k = 100은 그 순간에서 수렴하지 않아요.
- 한계: 이 모델은 1.75×10⁵ ~ 6×10⁵ V/cm에서 맞춘 계수예요. 배수를 채택하려면 근거가 필요하고, 지금은 "충돌 이온화가 이만큼 강하면 논문의 몸체 상태와
  같은 성질의 상태가 WL 꺼짐에서 저절로 생긴다"는 진단이에요.
- 라운드 7이 k = 6, 7에서 FBE 전체를 돌리고 있어요 (대리 생성 없음). 손실이 논문 크기로 나오는지가 다음 판단 근거예요.
