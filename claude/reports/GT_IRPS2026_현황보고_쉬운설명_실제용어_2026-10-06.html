Cho 외 (IRPS 2026) 소자 재현, 어디까지 왔을까요?

2026년 10월 6일 · 2D 단면 모델 기준 · 쉬운 문장으로 쓰되 용어는 실제 용어 그대로 · 대상 논문: "Row Hammer Effect and Floating Body Effect of Monolithic 3D Stackable 1T1C DRAM"

한 줄로무엇을 하고 있나요?

Cho 외 IRPS 2026 논문의 1T1C 3D DRAM 셀을 Sentaurus TCAD로 똑같이 만들고 있어요.
2D 단면 모델로는 거의 끝났어요.
Id–Vg, 쓰기, FBE 손실 곡선이 논문 그림과 맞아요.
로우 해머와 몸체 정공의 출처는 아직 재현하지 못했어요.

기본부터셀 구조와 두 가지 현상

셀은 액세스 트랜지스터 1개와 커패시터 1개예요.
저장 노드(SN)는 커패시터 쪽 전극이에요.
SN 전압이 1.1 V면 '1'을 저장한 상태예요.
비트라인(BL)은 전하를 넣고 빼는 수직 기둥이에요.
워드라인(WL)은 게이트예요.
몸체 위아래에 하나씩 있어요.
WL을 1.8 V로 올리면 채널이 열려요.
WL이 0 V면 채널이 닫혀요.
몸체는 채널이 생기는 p형 실리콘이에요.
이 몸체는 어디에도 접지되어 있지 않아요.
그래서 부유 몸체(floating body)라고 불러요.
몸체에 정공이 쌓이면 몸체 전위가 올라가요.
그러면 문턱 전압이 낮아져요.
WL이 0 V여도 전자가 BL에서 SN으로 새요.
SN 전압이 내려가요.
이것이 부유 몸체 효과(FBE)예요.
로우 해머는 이웃 셀 때문에 생기는 손실이에요.
이웃 셀의 WL을 계속 켰다 끄면 내 SN 전압이 조금씩 내려가요.
논문은 두 현상을 숫자로 보여 줘요.
2D 모델에서 같은 숫자가 나오면 재현 성공이에요.

조금 더1. 진행 지도

단계는 모두 여섯 개예요.
구조, Id–Vg, 쓰기는 논문과 맞아요.
FBE는 몸체 정공 전하를 조건으로 넣어서 맞췄어요.
로우 해머는 아직 논문과 달라요.
3D 모델은 중지 상태예요.

조금 더2. 시뮬레이션 전 구조 일치 검사

배치를 시작하기 전마다 구조를 논문과 대조해요.
게이트 길이 100 nm, 게이트 산화막 5 nm를 확인해요.
게이트 두께 20 nm, 수직 격리 30 nm도 확인해요.
몸체 두께와 도핑은 Case별로 확인해요.
메시에서 접합 위치도 읽어요.
50.00 nm와 175.00 nm여야 해요.
모두 맞을 때만 실행을 시작해요.
오늘 배치는 여섯 개였어요.
여섯 개 모두 통과한 뒤에 시작했어요.
첫 배치는 한 번 거부됐어요.
구조 파일 하나가 서버에 없었기 때문이에요.
파일을 올리고 다시 검사해서 통과했어요.

조금 더3. 점수판: 무엇이 좋아졌나요?

점수는 시뮬레이션과 논문의 차이를 허용오차로 나눈 값이에요.
1보다 작으면 그림 판독 오차 안이에요.
Id–Vg는 0.79에서 0.73이 됐어요.
Hurkx 터널링 계수 A를 1.7×1021로 낮췄어요.
그래서 GIDL 가지가 논문과 맞아요.
쓰기는 6.49에서 0.93이 됐어요.
저장 노드 용량을 1.8 fF로 바꿨기 때문이에요.
본문에는 4.2 fF라고 적혀 있어요.
그런데 Fig. 4(a)의 충전 속도는 1.8 fF일 때 맞아요.
FBE 손실은 6.62에서 0.84가 됐어요.
200 ns 손실은 5.14에서 0.51이 됐어요.
둘 다 몸체에 정공 전하를 넣은 결과예요.

조금 더4. 몸체 정공: 오늘 찾은 것

Fig. 8(a)는 몸체 전위 상승을 보여 줘요.
다섯 Case의 값은 555 / 445 / 365 / 320 / 368 mV예요.
그런데 필요한 정공 수는 거의 같았어요.
1084 / 1056 / 1099 / 962 / 1138개예요.
약 1050개, 전하로 0.17 fC예요.
이유도 찾았어요.
막대는 '공통 최종 전위 − 공핍된 몸체의 처음 전위'예요.
처음 전위가 Case마다 달라서 막대가 달라 보여요.
정공 1050개를 넣으면 몸체 전위 상승이 논문과 같아요.
그런데 그때는 SN 손실이 3~20배 작아요.
정공 1300개(0.21 fC)를 넣으면 손실 곡선이 논문과 같아요.
그때는 몸체 전위가 53~68 mV 더 높아요.
둘을 동시에 맞추지는 못했어요.
몸체 전위 60 mV가 전류 10배에 해당하기 때문이에요.
지금은 손실 곡선에 맞춰 두었어요.

조금 더5. FBE 손실 곡선: 논문과 나란히 보기

BL을 1.1 V와 0 V 사이에서 아홉 번 오르내렸어요.
BL이 0 V인 구간마다 SN 전압이 내려가요.
몸체가 두꺼울수록 손실이 커요.
Case 순서가 논문과 같아요.
첫 구간에서 많이 내려가요.
뒤로 갈수록 덜 내려가요.
이 꺾이는 모양도 논문과 같아요.
200 ns 손실은 82 / 56 / 16.6 / 12.5 / 1.6 mV예요.
논문은 100 / 50 / 14.6 / 7 / 1 mV예요.
첫 구간 손실은 18.9 / 16.0 / 6.4 / 5.3 / 0.14 mV예요.
논문은 55 / 29 / 7.1 / 3.5 / 0 mV예요.
Case 1과 2의 첫 구간은 논문보다 작아요.
Case 5는 손실이 거의 없어요.
논문도 그래요.

조금 더6. 아직 재현하지 못한 것 세 가지

첫째, 몸체 정공의 출처를 몰라요.
쓰기 중 충돌 이온화는 정공을 0~123개만 남겨요.
WL을 0.01 ps 만에 꺼도 28~258개예요.
유지 구간의 터널링은 정공을 충분히 만들어요.
대신 SN이 36~60 mV 처져요.
논문 곡선에는 그런 처짐이 없어요.
그래서 지금은 몸체에 일정한 생성을 넣었어요.
첫 BL 하강 직전(t_A)의 상태만 맞춘 조건이에요.
둘째, 로우 해머가 논문과 달라요.
Y–Y'는 사이클당 0.0007 mV예요.
논문은 0.0535 mV예요.
2D 단면에서는 BL 기둥이 이웃 WL을 가려요.
Z–Z'는 WL 저항 200 kΩ을 넣으면 0.0093 mV예요.
논문은 0.0100 mV예요.
다만 이 값은 한 번 생기는 결합 이동이에요.
쌓이는 손실이 아니에요.
충돌 이온화를 켠 Z–Z'의 급락(Fig. 7(a))은 나오지 않아요.
셋째, 3D 모델은 중지 상태예요.
켜져 있던 3D 실행 두 개도 중단했어요.

그래서?이제 무엇을 정하면 될까요?

2D 소자는 거의 완성이에요.
여기서 확정한 값을 3D 모델에 그대로 넣게 돼요.
그 뒤에 로우 해머와 패스 게이트 효과를 볼 수 있어요.
이제 네 가지를 정해 주세요.

  1. 몸체 정공 전하를 '조건'으로 넣는 방식을 계속 쓸까요?
  2. 정공 전하를 손실 곡선(약 1300개)에 맞출까요, Fig. 8(a) 막대(약 1050개)에 맞출까요?
  3. 로우 해머에 WL 저항 200 kΩ을 쓸까요, 이상적인 WL로 둘까요?
  4. 3D를 다시 시작할까요?
