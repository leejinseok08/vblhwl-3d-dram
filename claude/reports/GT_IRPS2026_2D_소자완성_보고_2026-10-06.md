## 2. 진행 절차 (개선 프로세스)

매 라운드를 아래 순서로 돌렸고, 프로젝트 지침(CLAUDE.md)에 고정해 두었어요.

1. **구조 일치 검사** (시뮬레이션 전 필수). `tools/gt_start.sh`가 배치에 들어가는 모든 구조를 논문과 대조하고, 전부 통과해야만 실행을 시작해요. 검사 내용은 `runs/<배치>.check`에 남아요.
   - 구조 파일의 치수: 게이트 길이 100, 게이트 산화막 5, 게이트 두께 20, 수직 격리 30 nm, 몸체 두께 30 / 20 / 10 nm, 소스·드레인 1×10²⁰, 채널 1×10¹⁸ 또는 1×10¹⁶ (Fig. 5(a), (b)), 스페이서 양쪽 25 nm (Fig. 2 그림 비율).
   - 메시에서 읽은 접합 위치와 도핑: 단일 셀·Z–Z' 50.00 / 175.00 nm, Y–Y' 25.00 / 150.00 / 250.00 / 375.00 nm.
   - 오늘 6개 배치 모두 통과 후 시작했어요 (run_d1, d2k, d2, d2f, d3, dfin).
2. **구성 실행.** 기준선에서 한 가지만 바꾼 구성을 만들어요 (`make_runs.py`의 `cfg2d`).
3. **채점.** `tools/score2d.py`가 `tools/paper_targets.py`의 논문 값과 비교해 그림별 점수를 내요.
4. **채택·기각.** 목표로 한 그림의 점수가 내려가고 Fig. 5(c)가 허용오차 안에 남을 때만 채택해요.
5. **새 기준선으로 다음 라운드.** 어떤 값도 점수를 움직이지 않으면 멈추고, 남은 것은 "재현 안 됨"으로 적어요.

논문 조건으로 넣은 것: 쓰기는 Fig. 4(a)대로(BL 1.168 V, WL 15~120 ps), 그 뒤 저장 노드 1.1 V에서 시작(Fig. 8(b), (c), 6(e), 7의 모든 곡선이 1.1 V에서 시작), FBE 타이밍은 Fig. 8(b) 픽셀 판독값(첫 BL 하강 21.0 ns, 주기 21.0 ns, 저전위 9회), FBE는 충돌 이온화 켬, 로우 해머는 BL ½Vdd에서 충돌 이온화 끔·켬 둘 다.

- 따라서 (1) 논문의 시작 전위가 이 구조의 것과 같고(두께·도핑·절연막·일함수에 대한 추가 검증), (2) t_A에서 논문의 몸체에는 정공 전하가 들어 있고, (3) 상승폭은 공핍 상태에서부터 센 값이에요. 채점 기준을 여기에 맞게 고쳤어요.
- 다른 탐침 위치나 다른 시점 조합으로는 다섯 값이 나오지 않아요 (BL 쪽 스페이서 아래 +673 / 623 / 586 / 586 / 584, 정공 준페르미 전위 342 / 297 / 307 / 322 / 9).
- 막대에 닿는 데 필요한 정공 수를 재 보면 1084 / 1056 / 1099 / 962 / 1138개예요. **다섯 Case가 모두 같은 정공 전하(약 1050개, 0.17 fC, 편차 8 %)**에 해당해요.

### 3.4 정공이 어디서 오는지 (재현 안 됨)

저자들의 설명은 Lee 외, "Monolithically Stackable 1T1C 3-D DRAM: A Technical Survey", IEEE TED 73(3), 2026, Fig. 3과 II-B절에 있어요: "holes generated by GIDL during BL precharge accumulate in the isolated body and can bias a parasitic n-p-n BJT". 이 설명은 Sentaurus 옵션이나 계수를 정해 주지 않아요. IRPS 논문은 충돌 이온화 모델을 켰을 때 몸체가 뜬다고 해요 (Fig. 7(e): 끔 2.4 mV, 켬 665 mV).

이 모델에서 시험한 경로와 결과예요.

| 경로 | 몸체에 남는 정공 [개], Case 1~5 | 필요량 약 1050개 대비 |
|---|---|---|
| 쓰기 중 충돌 이온화 (쌍 894 / 709 / 609 / 851 / 802개 생성) | 123 / 41 / 13 / 3 / 0 | WL이 켜진 동안 저장 노드 쪽으로 빠져나감 |
| WL 하강 1 ps | 177 / 87 / 55 / 25 / 5 | 부족 |
| WL 하강 0.1 ps | 200 / 141 / 98 / 63 / 11 | 부족 |
| WL 하강 0.01 ps | 258 / 159 / 122 / 78 / 28 | 부족, Case마다 다름 |
| 유지 구간의 터널링 (저장 노드 쪽 접합, 어제까지의 보정) | 필요량을 만들 수는 있음 | 저장 노드가 36~60 mV 처짐. 논문에는 처짐이 없음 |
| 충돌 이온화 구동력 3종, BL 접촉, 밴드갭 좁아짐, 메시 | 변화 없음 | — |

정공 1050개는 0.17 fC이고, 저장 노드 쪽에서 만들면 노드가 40~90 mV 내려가요. 논문 곡선에는 t_A까지 처짐이 없으니 전자는 BL 쪽으로 빠졌거나 정공이 FBE 구간 시작 전에 이미 들어가 있어야 해요. 논문에는 프리차지에서 FBE 구간으로 넘어가는 과정이 나와 있지 않아요.

### 3.6 로우 해머 (2D 단면)

Fig. 7(b)의 R을 맞춤 변수로 본 결과예요 (Z–Z', Case 2, 충돌 이온화 끔, 본문 Cs).

|---|---|---|---|---|
| 1×10⁻⁴ (이상적) | +0.011 | −0.0011 | +0.0007 | 0 |
| 2×10⁵ | −0.099 | **+0.0099** | +0.0024 | +211 |

- 논문 Z–Z' 0.0100 mV/사이클은 R = 2×10⁵ Ω에서 나와요. 단, 처음 몇 사이클의 결합 이동 한 번을 10사이클로 나눈 값이고 반복해서 쌓이는 손실이 아니에요. 논문 조건(저장 노드 1.1 V 시작)으로는 0.0093이에요.

Case 1은 첫 구간에 3557쌍이 생겨요. 몸체의 정공이 1551개에서 1762개로 오히려 늘고 노드가 404 mV 내려가요.
2. **Id–Vg가 스윕 시간에 따라 달라지는 이유.** 켜진 전류가 만든 정공이 부유 몸체에 쌓여서 문턱 전압을 내려요. 쌓이는 데 시간이 걸려요. 그래서 스윕 시간마다 곡선이 달라요. 충돌 이온화를 끈 대조 실행은 두 스윕 시간 모두 DC 곡선과 같아요. 즉 어긋남은 스윕이 아니라 충돌 이온화 때문이에요.
3. **부산물 1: BL 접촉 위치.** 모델과 정공 전하는 그대로 두고 접촉만 기둥 끝으로 옮기면 손실이 커져요 (Case 1: 91 → 147 mV, 몸체의 정공은 1579개와 1578개로 같음). 제 해석은 이래요. BL이 0 V인 동안 BL(N+)–몸체(p)–저장 노드(N+)는 기생 n-p-n BJT이고 BL이 emitter예요. 접촉이 접합에서 50 nm에 있으면 몸체에서 넘어온 정공을 바로 흡수해요. base 전류가 커서 전류 이득 β가 작아요. 접촉이 멀면 β가 커져요. 이 해석만 따로 가르는 실행은 하지 않았어요.
4. **부산물 2: avalanche 모델을 Fig. 8에서 끄면.** `fin3`에는 기본 구동력의 avalanche 모델이 켜져 있어요 (2026-10-06 사용자 조건). 이 모델은 유지 구간에 대체 생성의 쌍을 1.13~1.22배로 불려요. 첫 BL-low 구간에도 169쌍(Case 1) / 42쌍(Case 2)을 보태요. 모델을 끄고 대체 생성률을 × 1.23 / 1.195 / 1.14 / 1.135 / 1.18로 올려 막대에 다시 맞췄어요 (정공 1597 / 1366 / 1302 / 1126 / 1344개). 그러면 Case 1의 손실이 구간마다 61 / 77 / 86 / 93 mV, 200 ns에 113 mV예요. 논문은 55 / 67 / 76 / 83, 100 mV예요. `fin3`는 91 / 120 / 137 / 149, 183 mV였어요. 쓰기 점수는 0.93에서 1.11로 조금 나빠져요.
5. **판정.** (가)는 기각이에요. ElectricField는 Fig. 7에만 쓰는 후보로 남아요. `fin3`는 바꾸지 않았어요. 두 부산물은 사용자의 결정이 필요해요.

### 9.18 Case 5: 논문의 0과 우리의 0.13 mV (2026-10-07 밤, 사용자 질문)

**질문 (사용자).** Case 5에서 논문은 시작이 0인데, 우리(0.13 mV)와 무엇이 달라서인가.

**한 줄로.** 첫 구간의 0과 0.13 mV는 차이가 아니에요. 논문 그림의 픽셀 한 줄이 0.47 mV라서 0.13 mV는 보이지 않아요. FBE 누설이 없다는 점은 우리 모델도 논문과 같아요. 우리 값 0.13 → 1.58 mV는 FBE가 아니라 저장 노드 접합의 GIDL 누설이에요. 진짜 차이는 200 ns에 있어요. 우리 1.58 mV, 논문 0.5 mV 이하예요. 새 실행은 없어요.

**용어.** GIDL(gate-induced drain leakage): 게이트가 0 V이고 옆의 N+가 1.1 V일 때, 게이트 가장자리 접합의 강한 전기장에서 band-to-band tunnelling으로 전자–정공 쌍이 생기는 누설이에요. 전자는 N+(저장 노드)로, 정공은 몸체로 가요.

1. **논문이 0인 이유.** 논문은 Fig. 8(c)에 "V_th0(WF = 5.0 eV) > V_th0(WF = 4.7 eV)"라고 적었어요. 게이트 일함수가 0.3 eV 크면 문턱 전압이 약 0.3 V 높아요 (Fig. 5(c)에서 Case 4 0.26 / 0.39 / 0.51 V, Case 5 0.53 / 0.65 / 0.78 V). subthreshold 전류는 60 mV마다 10배씩 줄어요. 0.3 V면 10⁵배 작아요. 그래서 몸체 전위가 368 mV 올라도 WL 0 V에서 채널이 열리지 않아요.
2. **우리 모델도 같아요.** `fin3`의 Case 5 (`project/tools/gt_fbe_leak.py`):

| | Case 3 | Case 4 | Case 5 |
|---|---:|---:|---:|
| 손실 속도, BL이 0 V인 구간 [µV/ns] | 145 | 105 | 8.82 |
| 손실 속도, BL이 1.1 V인 구간 [µV/ns] | 6.2 | 5.7 | 8.78 |
| 몸체의 정공, t_A → 200 ns [개] | 1294 → 1011 | 1118 → 832 | 1335 → 1351 |

   - FBE 손실은 BL이 0 V일 때만 생기고, 몸체의 정공이 빠져나가요 (Case 3, 4).
   - Case 5는 BL이 높든 낮든 속도가 같아요. 정공도 빠져나가지 않아요. 잃은 전자 15.2개는 생긴 쌍 15.8개와 같아요.
   - 즉 Case 5의 손실은 전부 저장 노드 접합의 GIDL이에요. 전류로는 13.6 pA예요 (I = C·dV/dt = 1.54 fF × 8.8 µV/ns).
   - 이 누설은 다른 Case에도 있어요 (BL이 높은 구간 6.9~10.1 pA). FBE 손실에 가려 있을 뿐이에요.
   - avalanche 모델을 꺼도, 몸체의 정공을 1134 / 1413개로 바꿔도 같아요 (1.58 / 1.60 / 1.57 mV).
3. **논문 그림을 다시 읽었어요.** Fig. 8(c)의 오른쪽 그래프(확대)는 한 픽셀 줄이 0.47 mV예요 (1.1 V가 462~463줄, 1.0 V가 674줄. 빨간 곡선의 끝값 14.5 mV로 눈금을 확인). 1.1 V 높이의 가로선은 121 ns부터 200 ns까지 파랑이고 (그 앞은 검정) 같은 두 줄에 있어요. 이 파란 부분을 ⑤의 곡선으로 읽었어요. 그러니 논문의 Case 5는 "0 → 1.0 mV"가 아니라 "200 ns까지 0.5 mV 이하"예요. 표에 쓴 1.0은 처음 읽을 때의 상한("1 mV 이내")이었어요.
4. **그래서 차이는 200 ns예요.** 우리 1.58 mV는 그 그림에서 3.3줄 아래라서 보였어야 해요. 논문에는 없어요. 후보는 둘이에요.
   - 저장 노드 용량: 같은 전자 15~17개가 본문의 3.6 fF에서는 0.68~0.74 mV예요 (3.6 fF로 돌린 `Db0F_c5`: 0.738 mV). 우리는 쓰기 곡선에 맞춘 1.54 fF를 써요.
