> **2026-10-10 14:24 사용자 결정: 접지 몸체(grounded body) 경우는 재현에서 제외.** 이 문서의 접지 셀 내용은 기록으로만 남아요. 재현율은 scope51(35 / 51 = 68.6 %)이고, P2는 부유 쌍 2건이에요.

사용자 지시: "A랑 B1~B3 진행해". 배치 `run_gbd.sh` 9건은 13:55:17에 시작해 14:11에 모두 끝났어요. 실행 전에 구조 점검을 했고 ALL PASS였어요. 등록은 GitHub `claude/EXPERIMENTS.md`(53955be)에 있어요.

## 결론

1. **원인은 몸체를 0 V로 붙잡는 접촉 자체예요.** 같은 자리, 같은 크기의 SiO2 슬롯(접촉 없음)은 DC 전류(차이 0.1 µA 이하)와 쓰기(차이 1 mV 이하) 모두 부유 셀과 같아요 (B2).
2. **정지는 DC 성질이에요.** 접지 셀의 DC 충전 전류는 노드 0.6 V에서 24 µA, 0.72 V에서 2.3 µA, 0.82 V에서 0.1 µA로 끊겨요. 과도 전류도 같은 노드 전압의 DC 전류와 같아요 (B1).
   - 끊길 때 BL–노드 전압은 게이트 채널에 걸려요(86 – 100 %). 부유 셀에서는 스페이서 아래에 걸렸어요.
   - 노드(소스)가 올라갈수록 몸체–소스 역바이어스가 커지고 문턱이 올라가서 채널이 꺼진다고 해석해요(body effect).
3. **논문에 없는 접촉 길이는 정지 전압을 조금만 옮겨요.** write peak가 0.720 / 0.780 / 0.842 V예요(20 / 10 / 5 nm). 어느 길이도 1.1 V에 닿지 않아요 (B3).
4. **A:** 두 몸체 모두 접지 접근이 있는 `gb2_zzg2`를 만들었고 구조 점검을 통과했어요. 접촉 `body_v`, `body_a`도 확인했어요. P2 접지 덱 `DnwRzbg_zz`는 이 구조를 써요. 실행은 G1 뒤예요.

- **과도 = DC:** 접지 20 nm 셀의 과도 전류 83.5 / 32.4 / 13.0 / 5.7 µA가 같은 노드 전압의 DC 94.1 / 36.5 / 13.6 / 7.2 µA와 거의 같아요(+12 / +24 / +39 / +60 ps).
- **`body_v` 전류:** 전자 전류는 0.2 µA 이하예요. 정공 전류는 +6 ps에서 최대 −10.9 µA로, 충돌 이온화로 생긴 정공이 빠져나가는 거예요. WL 교차 순간의 변위 전류 −18.7 / −12.5 / −9.2 µA는 슬롯 길이에 비례해요. 게이트와 접촉 사이의 용량 결합이에요.
- **일관성:**
  - 단일 셀 접지 20 nm는 기존 쌍 실행 `DptRzbg_zz`와 같아요(+12 ps 0.415 대 0.418 V, peak 0.7199 대 0.7195 V).
  - 단일 셀 부유는 Codex의 쌍 실행 `CxN4Atk`와 같아요(0.485 / 0.696 / 0.846 / 0.960 대 0.485 / 0.696 / 0.845 / 0.959 V).
  - BE 전하 수지 잔차는 모든 실행에서 0.0000 fC예요.
- **수치:** 시간 설정은 Codex P1 h/4(잠정, G1 전)예요. h/2 → h/4에서 쓰기가 움직인 양은 최대 2.3 mV이고, 여기의 차이는 수십 – 수백 mV예요. 메시 수렴은 G1 판정을 기다려요.

## 해석과 남은 것

- 우리 2D 모델에서 몸체를 0 V로 붙잡은 셀은 WL 1.8 V로 0.72 – 0.84 V 위로 쓰이지 않아요. 접촉 길이를 20 nm에서 5 nm까지 줄여도 마찬가지예요.
- 논문 Fig.7(c)의 접지 곡선은 1.1 V에서 시작해요. 그 상태를 어떻게 만들었는지는 논문에 없어요.
- 남은 기하 미지수는 하나예요. 2D 단면의 접촉은 셀 폭 100 nm 전체를 덮는 판이에요. Fig.7(b)의 Ground Access가 폭의 일부만 차지하는 선이라면 채널이 접촉을 돌아서 흐를 수 있어요.
