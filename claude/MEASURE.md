# 측정 기준 — Cho 소자 (VBL/HWL 1T1C 3D DRAM) TCAD 재현

정한 날: 2026-10-08 (사용자 지시: Codex의 `소자특성_측정평가기준_학습기록_2026-10-08.md`와 `Cho_조사결과_개선방안_eliU_2026-10-08.md`를 참고해서 측정 기준을 세운다).
사용자가 밝힌 본뜻 (같은 날 오후): 이 기준은 **소자의 전기적 특성을 잴 때 BL의 어디를 잴지 정할 때** 참고하라는 것. 그 답은 4.6절이에요.
쓰는 곳: Claude가 하는 모든 채점, 표, 보고. 도구는 `tools/paper_targets.py`(목표값), `tools/score2d.py`(점수), `tools/repro_rate.py`(재현율), `tools/gt_cap.py`(용량).

이 문서의 허용 오차와 판정 규칙은 **이 프로젝트가 정한 것**이에요. IEEE나 IEDM의 공식 합격 기준이 아니에요 (Codex의 조사: 모든 MOSFET에 공통인 V_th 기준 전류, SS 합격값, 재현 오차는 공식 안내에 없음).

## 1. 원칙

1. 순서는 **정의 → 조건 → 추출법 → 수치 비교**예요. 정의나 조건이 다른 숫자는 비교하지 않아요.
2. 숫자마다 **종류**를 적어요 (3절). 논문 값도 "명시값"과 "그림에서 읽은 값"이 달라요.
3. 맞추는 데 쓴 숫자와 맞춘 뒤에 나온 숫자를 나눠요 (2절). 같은 자료로 맞추고 통과한 것을 검증이라고 부르지 않아요.
4. 평균(RMS 점수, 재현율)은 요약으로만 써요. 항상 **Case별 값과 가장 크게 벗어난 항목**을 같이 보여요.
5. 전압 손실은 전류와 용량으로 나눠서 봐요: ΔQ = C_S · ΔV, I = ΔQ / Δt. 전압만 맞으면 둘 중 무엇이 맞았는지 알 수 없어요.
6. 논문의 추출법을 바꾸지 않아요. 일반 FET 보고 권고(Cheng 외, Nature Electronics 2022)에 있는 지표는 보조로만 더해요.
7. **구성 하나는 물리 모델 한 벌이에요** (사용자, 2026-10-08). 어떤 현상(예: 충돌 이온화)을 필요한 구간이나 그림에서만 켜지 않아요. 켜면 그 구성의 모든 측정(Id–Vg, 쓰기, FBE, 로우 해머)에 켜고, 그 조건에서 다른 값들도 다시 정해요. 논문이 조건을 나눈 곳(Fig. 6(e)는 충돌 이온화 없음, Fig. 7은 있음)만 구성을 둘로 나눠요.

### 4.2 저장 용량 C_S

- 정의: 모든 단자 0 V에서 소신호 AC 해석(1 MHz)으로 얻은 용량 행렬의 C(SN, SN). 접지·WL·BL로 가는 몫을 따로 적어요 (`tools/gt_cap.py`).
- 세 값을 항상 구분해요: **본문 값** 3.6 / 4.2 / 5.1 fF (저자가 치수로 계산), **그린 구조의 값** 4.05 / 4.15 / 4.25 fF (Fig. 2 단면대로 그린 구조의 AC 결과, 라운드 32), **맞춘 값** 1.8 fF (쓰기 곡선에 맞춤, fin5).
- 표의 손실 [mV]에는 그 실행의 C_S를 같이 적어요.
- 본문 값과 그린 구조의 값은 **다른 것**이에요 (NOTES (by)). 본문 값은 감지 여유 식에 넣은 설계값이에요: Fig. 5(d)의 점 9개가 ΔV = (V_DD/2)·C_S/(C_S + C_BL)에 3.6 / 4.2 / 5.1 fF를 넣은 값과 1.5 mV 안에서 같아요. 그린 구조는 용량의 90 %가 몸체 두께와 무관한 면에 있어서 4.05 → 4.25 fF로만 변해요. 저자의 계산식은 논문에 없어요.
- Case 사이의 용량 비율은 본문 값(5.1 : 4.2 : 3.6)을 따르고 있어요. 이것은 가정이에요 (논문의 과도 해석 구조가 어느 값을 가졌는지는 적혀 있지 않음).

### 4.3 쓰기 (Fig. 4(a))

- 정의: WL이 0.9 V를 지나는 시각(상승 에지의 중간)에서 12 / 24 / 39 / 60 ps 뒤의 V_SN.
- 조건: BL 1.168 V (판독), WL 0 → 1.8 V (15 ps 부근), 105 ps 동안 켜짐. Case 2.
- 논문 값: 0.72 / 0.92 / 1.06 / 1.13 V (판독). 허용 오차 0.03 V.
- 같이 적는 것: 구간별 평균 충전 전류 I = C_S · ΔV / Δt [µA]와 그때의 C_S. 본문 용량 4.2 fF로 읽으면 논문 곡선은 252 / 70 / 39 / 14 µA예요.
- **Fig. 4(a)는 Case 2로 읽어요** (사용자, 2026-10-08). 근거는 본문이에요: "Prior to RHE/FBE simulation, the cell was pre-charged through transient simulation (Fig. 4(a))", 그리고 RHE 시뮬레이션의 셀은 Case 2예요. 그림에 Case 표시는 없지만 이 읽기를 써요. Case 4의 셀이 곡선에 더 가깝다는 것(NOTES (ca))은 진단 결과로만 남겨요.
- Fig. 4(a)는 precharge라서, 끝난 뒤의 노드 전압이 RHE·FBE 곡선의 시작값(1.1 V)이어야 해요. 쓰기를 채점할 때 WL이 꺼진 뒤의 노드 전압도 같이 적어요 (`fin7` Case 2: 1.022 V. 그래서 지금은 노드를 1.1 V로 직접 맞춰 주고 있어요).
- 쓰기 전류의 진단은 DC 충전 전류로 해요 (`tools/gt_loadline.py`): 게이트 1.8 V, BL 1.168 V에서 노드 전압을 0 → 1.168 V로 올리며 노드로 들어가는 전류. 전자 quasi-Fermi 전위로 BL–노드 전압이 어디에 걸리는지 같이 적어요.

같이 적는 것:
- 몸체 정공 수와 만든 방법 (대리 생성률과 구간, 또는 자체 생성과 유지 시간), SN을 고정한 구간.

- 200 ns 곡선은 ms 단위 retention의 증거가 아니에요.

### 4.5 로우 해머 (Fig. 6(e), Fig. 7)

조건: BL 0.55 V, 피해 셀 SN 1.1 V('1'), 공격 WL 0 ↔ 1.8 V, 94 ps 켜짐 + 94 ps 꺼짐을 1사이클로 세고 10사이클. 방향 Y–Y' / Z–Z' / X–X'. Fig. 6(e)는 avalanche 모델 없음, Fig. 7은 있음.

| 항목 | 정의와 추출법 |
|---|---|
| 가역 스윙 | 한 사이클 안에서 공격 WL이 높을 때와 낮을 때의 V_SN 차이 [mV]. 커패시터 분압 ΔV = ΔV_WL · C_결합 / C_S로 결합 용량을 구함 |
| 잔류 손실 | 같은 위상(공격 WL 상승 20 ps 전)에서 읽은 V_SN의 사이클당 감소 [mV/사이클]. 10사이클 평균과 마지막 5사이클 평균을 같이 적음 |
| idle 손실 | 같은 덱에서 공격 WL만 0 V로 둔 대조 실행의 같은 시간 동안 손실. 셀 자체의 누설 |
| **공격 순효과** | **잔류 손실 − idle 손실**. 논문의 0.0535 / 0.0100 / 0.0060 mV/사이클과는 이 값을 견줘요 |
| 몸체 전위 상승 (Fig. 7(e)) | t = 0에서 첫 공격 펄스의 끝(0.09 ns)까지. 논문 665.1 mV (모델 켬), 2.4 mV (끔), 1.8 mV (접지 몸체) |

- idle 대조 실행이 없는 값은 "자체 누설 포함"이라고 적어요. fin5의 0.0014 mV/사이클은 유지 누설 13.5 pA × 188 ps / 1.8 fF와 같아서 **순효과는 0에 가까워요** (라운드 15의 대조 실행: attack − idle = 0.0000).
- 다음 로우 해머 배치부터 방향마다 idle 실행을 같이 돌려요.
- 해머 횟수 N = 허용 손실 / 사이클당 손실은 기울기가 유지된다는 가정의 외삽이에요. 논문의 11.3k / 60.5k / 100.8k도 그렇게 계산한 값이고, 첫 비트 오류 횟수(HCfirst)의 측정이 아니에요. 우리 표에는 mV/사이클만 채점해요.

### 4.6 BL을 어디서 재는가 (사용자 지시의 본뜻, 라운드 34)

사용자: 측정 기준은 "소자의 전기적 특성을 잴 때 **BL의 어디를 잴지** 정할 때" 참고한다.

**기준에서 가져온 것** (Codex 학습기록 2절, 3절, 6절): 단자 특성은 소자의 단자에서 재고, 단자 방향과 접촉 구조를 적는다. 원문 구조와 맞는지 먼저 확인한다. 위치를 바꿨을 때의 차이를 그 지표의 단위로 적는다.

**논문의 BL** (Fig. 2 단면, 그림 판독): N+ 기둥이 스택 맨 위에서 바닥층까지 다섯 층을 지나가요. 그러니 논문 모델의 BL 단자는 기둥의 끝이고, 셀에서 Z 피치 0~4개 떨어져 있어요. 어느 층의 셀을 계산했는지는 논문에 없어요.

**BL에서 재는 것**: ① Id–Vg의 드레인 전류 = BL 단자의 전체 전류. ② 쓰기·FBE·로우 해머의 V_BL = BL 단자에 건 전압. ③ FBE에서 BL 접촉은 몸체에서 기둥으로 넘어온 정공이 빠져나가는 곳이기도 해요 (기생 n-p-n BJT의 베이스 전류). 그래서 접촉의 위치가 결과에 들어가요.

**정한 것** (사용자 결정, 2026-10-08 16시: "pb2로 바꿔줘". 이 위치의 소자가 지금의 기준 구성 `fin6`이에요)

1. BL은 **기둥 끝의 접촉**에서 재요. 기둥 축은 우리 반쪽 모델의 대칭면이에요. 논문 구조에 그런 단자가 없어서 쓰지 않아요.
2. 접촉은 셀에서 **Z 피치 2개 이상** 떨어뜨려요 (구조 `gb2_*`). 그 뒤로는 값이 접촉의 위치에 따라 변하지 않아요: 2 → 4 피치에서 첫 구간 손실 +2 % / +1 %, 200 ns 손실 +5 %.
3. Id–Vg와 쓰기는 어디서 재도 같아요 (Id–Vg 0.01 decade, 쓰기 10 mV 안). 지금까지의 값을 그대로 써요.
4. FBE 손실은 접촉의 위치에 따라 최대 2.2배 달라져요 (Case 1 첫 구간 61 → 134 mV). 손실을 적는 표에는 BL 접촉의 위치를 반드시 같이 적어요.
5. 한 층짜리 기둥의 끝(fin5)은 "접촉 바로 옆 층의 셀"이라는 특수한 경우예요.

**이 위치에서 다섯 Case** (구성 `pb2`): 첫 구간 131.3 / 29.1 / 6.0 / 4.8 / 0.24 mV (논문 55 / 29 / 7.1 / 3.5 / 0.5 이하) → 4 / 5. 나중 손실 312 / 109 / 24.3 / 7.9 (Case 4는 둘째 구간 뒤) / 1.59 mV (논문 100 / 50 / 14.6 / 5.0 / 0.5 이하) → 2 / 5. fin5는 5 / 5와 4 / 5였어요. 다른 항목을 fin5의 값 그대로 두면 (Id–Vg는 Case 2만, 로우 해머는 이 위치에서 다시 재지 않았어요) 예측 항목은 9 / 15 → 6 / 15, 전체는 39 / 52 → 36 / 52예요.

**한계**: 이은 기둥 옆에는 다른 층의 셀을 넣지 않았어요 (산화막 속의 N+ 기둥). 기둥 안의 정공 수명은 Sentaurus 기본 SRH 모델이고 Auger 재결합은 없어요. 피치 2개부터 값이 변하지 않는다는 것은, 그때부터 정공이 접촉이 아니라 기둥 안의 재결합으로 사라진다는 뜻이라서 이 가정이 결과에 들어가요.

## 6. 보고서와 표의 형식

1. 표의 "논문" 칸에는 종류(명시 / 판독 / 상한)와 읽은 그림·곡선을 적어요.
2. "모델" 칸에는 실행 이름, C_S, 정공 조건을 적어요.
3. 손실은 "1.1 V − 곡선 [mV]"라고 단위와 함께 적어요.
4. 재현율은 2절의 세 숫자(전체 / 보정 / 예측)와 가장 나쁜 항목을 같이 적어요.
5. 조건을 넣어 맞춘 것은 "조건부 재현", 공개 조건만으로 나온 것만 "재현"이라고 써요.
6. 720개 조합처럼 일부 항목을 뺀 채점은 뺀 항목을 같은 문장에 적어요.
